# Файлы для итогового задания
Проект создан для реализации web сервера с заметками.
В приложении через браузер можно посмотреть список текущих задач, создать новые или удалить старые. Также можно менять уже существующие задачи.
У каждой задачи есть обязательные поля для заполнения, такие как дата, заголовок. И необязательные - комментарий и правила повторения (повтор с интервалом, по дням, месяцам и годам)
Задачи со звездочкой выполнены:
1. Определять путь к файлу базы данных через переменную окружения. Для этого сервер должен получать значение переменной окружения TODO_DBFILE и использовать его в качестве пути к базе данных, если это не пустая строка.
2. Указание дней месяца для повторения через запятую (насколько я понял из задания, то здесь во фронте проставляются нужные галки на дни недели при еженедельном повторении или цифры через запятую при указании дней месяца, при этом галки ставятся на все месяцы)
3. Реализован поиск задач по дате в формате дд.мм.гггг или ключевым словам в названии или комментариях


Директория project содержит файлы бэкенда (выполнение заданий)

1. Создание базы данных
Содержит 2 операции:
Функция dbcreate открывает файл scheduler.db. Если файла нет, то создает в текущей папке (./data/scheduler.db)
Функция dbopen создает подключение к файлу scheduler.db

2. Правила повторения задач
В функции tasks/tasks.go находится структура с полями задачи. К ней обращаются все обработчики
В директории handlers находятся обработчики:
Date.go обрабатывает с правилами повторения задач
Handlers.go содержит все обработчики API
Task.go обрабатывает сами задачи : создание, удаление, обновление, возвращает список всех задач, отмечает задачи как выполненные
Validation.go проверяет, поддерживается ли правило повторения

3. Функция validation.go должна проверять пароль для входа в планировщик

4. Main.go запускает сервер, регистрирует обработчики и подключает папки с фронтэндом

5. В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере. Немного исправлены тесты, комментарии оставлены

6. Директория `web` содержит файлы фронтенда.
